# Numerical validation

The independent numerical reference is the original NOAA/NASA/USAF [U.S. Standard Atmosphere, 1976](https://ntrs.nasa.gov/citations/19770009539), NASA-TM-X-74335 / NOAA-S/T-76-1562. [Fixture provenance](../testdata/README.md) identifies the downloaded NOAA PDF by checksum, its printed pages, units, transcription method, and the report's prescribed corrections. Tests run offline from committed data. Expected table values are not generated by this library.

Measurements below use Go 1.27.3-X:nodwarf5 on Linux amd64, 2026-11-04. A test budget is an enforced tolerance; the observed maximum is the actual largest discrepancy in the selected rows, rounded upward at the displayed precision. These comparisons include the finite precision of the printed tables, so their error is not solely numerical integration error.

The nine Table II rows independently cover the remaining state quantities; the molar-mass budget reflects that table's coarsest three-significant-digit entries. Ten additional thermal-conductivity cases agree with a 60-digit evaluation of the defining Eq. (53) to a relative tolerance of `1e-14`. The main conductivity tables contain errors and are not used as a conductivity oracle. All 13 Table 8 molecular-weight ratios are checked, along with the more precise Table 9 species boundary values at 86 km, seven geopotential layer bases, and sea-level transport values.

The temperature comparisons follow the report's explicit instructions on printed p. 9 for correcting the 80–86 km tables with Table 8. The committed Table I values remain the printed values; expected kinetic temperatures are corrected in the test using independent Table 8 data. The library's equations already applied that correction. This avoids altering the implementation to reproduce a documented tabulation discrepancy.

## Numerical and behavioural checks

The production upper-atmosphere solver uses RK4 steps of at most 100 m below 150 km and 1 km above it, splitting at equation changes, the requested height, and the hydrogen reference height. A test repeats the integration at half and quarter step sizes, retaining the same equations and breakpoints. At 15 heights covering the upper layers, fractional heights, both sides of the hydrogen reference, and the 1,000 km endpoint, the largest default-versus-quarter-step discrepancy across the six species is `1.487e-9` relative. Half-versus-quarter differs by at most `8.776e-11` relative. Both comparisons enforce a `1e-6` relative budget. This is a step-size sensitivity check; a mistake shared by the defining equations would require the independent published comparisons to detect it.

A 1 km grid checks all 1,006 state samples from −5 to 1,000 km for finite positive quantities and decreasing pressure, density, and gravity. At the 915 upper-atmosphere grid points it also checks nonnegative finite species, their sum against the state, and the particle equation of state using the report's adopted constants. Other tests cover equation boundaries, invalid and nonfinite inputs, explicit units and conversion round trips, transport and composition domains, fuzz seeds, concurrent calls, and exact cached/direct equivalence. A separate comparison found 3,156 state, species, and transport outputs in SI and imperial units byte-identical to the implementation before an internal refactor during pre-release development.

Transport robustness tests cover zero and partially constructed states, nonfinite and nonpositive inputs, all four temperature units' absolute-zero limits, valid negative Celsius/Fahrenheit temperatures, geometric altitude boundaries in all length units, input conversion overflow/underflow, and unrepresentable output conversions. Error cases must return zero properties. A 20-second SI/imperial fuzz campaign on 2026-11-06 exercised 1,429,655 cases without failure; successful calls must have valid consumed inputs and finite positive outputs. This is additional behavioural validation, separate from the scientific reference comparisons.

## What the results establish

The README's numbers describe agreement with selected published reference points, after specified corrections. They are not a statistical confidence interval, a proven uniform bound at every possible altitude, or an estimate of the model's agreement with actual atmospheric conditions. COESA 1976 is a fixed reference atmosphere; time, position, weather, and changing solar conditions are outside this API's inputs. The model retains its adopted 1976 constants, including independently rounded constants, rather than substituting current physical constants.

Reproducibility is numerical within a specified build. The tests use tolerances rather than requiring identical floating-point bits across compilers and architectures. CI runs the shared correctness and race tests on Linux amd64/arm64, macOS amd64/arm64, and Windows amd64. [Compatibility policy](compatibility.md) defines the supported inputs and numerical expectations. Coverage and race detection support implementation quality but do not measure scientific accuracy. Published-reference tests, refinement, physical checks, and concurrency tests address different failure modes.

## Reproduce

```sh
go test . -run 'TestPublished|TestMolecularWeightCorrection|TestThermalConductivityEquation|TestIntegrationRefinement|TestPhysicalProfiles' -count=1 -v
./scripts/local_ci.sh
# Optional bounded transport fuzzing campaign:
go test . -run '^$' -fuzz '^FuzzTransport$' -fuzztime=20s
```

The verbose reference tests print actual maximum absolute and relative discrepancies with their coordinates. Fixture schemas and row counts are checked so accidentally removing data cannot silently reduce the advertised validation set. Run `python3 scripts/generate_thermal_reference.py` only when intentionally regenerating the independent Eq. (53) fixture.
